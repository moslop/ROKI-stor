# LUXE FASHION

A bilingual (Arabic + English) static website for a fashion store featuring a client-side admin panel.

## Features
- **Homepage:** Features a 3-image responsive gallery and a dynamic product list.
- **Bilingual:** Support for Arabic and English with an easy toggle.
- **Admin Panel:** A built-in, password-protected (code: `CNSy7zbs`) admin section to manage products and homepage images using `localStorage`.
- **Cart & Orders:** Fully functional shopping cart that sends final order details via WhatsApp.
- **Responsive:** Designed to work perfectly on mobile and desktop.

## Admin Access
To access the admin panel, click the "المسؤول" or "Admin" link in the navigation bar. Use the code `CNSy7zbs` to log in.

## Security Disclaimer
**Note:** This website uses a client-side admin panel and `localStorage` for data storage. This implementation is **not secure** for production environments where sensitive data or multi-user access is required. It is intended for static hosting or small personal projects.
